# Открытые проверки и ограничения

## Состояние записей и резервных копий

Планы содержат полный payload и лежат в service-owned каталоге 0700, файлы0600.
Десятиминутный expiry запрещает исполнение, но не удаляет текст с диска.
Consumed markers, results и журнал сохраняются для запрета повторов и сверки
неизвестного исхода. Автоматической очистки и квоты пока нет. До массовой
автоматизации оператору нужен контроль размера state/disk; следующий отдельный
шаг — ограничение pending plans и reviewed retention без удаления evidence
для unknown или возможности повторно исполнить consumed plan.

write-profile создаёт защищённую копию config с credentials при каждом реальном
переключении. Копии доступны только root; срока автоматического удаления нет.
Оператор проверяет место и организует защищённое хранение/retention, сохраняя
рабочую recovery-копию. Эти файлы никогда не копируются в Git или отчёты.

## Приёмка VK

Весь расширенный каталог ещё не проверен на живых правах. Наличие group/service
при отсутствии user не даёт доступа большинству операций wall/media/market
и статистике. Реальные отправки, публикации, изменения и удаления в выпускной
проверке не выполняются. Проверять их только на конкретном разрешённом владельцем
сценарии с точными объектом, payload и независимым receipt.

## OAuth и клиенты

Автоматическое обновление действующего ChatGPT grant подтверждено после
естественного expiry. Fixture-проверки не заменяют реальный аварийный restart,
восстановление после потери диска и expiry refresh. Claude пока не подключён.
