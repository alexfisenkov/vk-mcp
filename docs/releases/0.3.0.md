# VK MCP 0.3.0

Расширенный каталог сообществ: 100 методов VK и два фиксированных media-сценария;
50 MCP-инструментов. Новые семейства: обсуждения, опросы, истории; расширены
модерация стены/участников, сообщения, документы, фото, видео и товары.
Длинный список действий доступен через vk_search_methods / vk_describe_method;
частые действия имеют отдельные именованные инструменты.

Добавлены vk_communities и подробный vk_capabilities: агент получает числовые
ID и отличает отсутствие ключа от локально выключенной записи и отказа VK.
Удаления проходят тот же план, независимый receipt, одноразовое исполнение
и журнал, что и прочие изменения. Прямые read endpoints выдачи upload server
убраны из каталога; fixed media composites остаются.

Добавлен операторский write-profile helper с dry-run, сохранением credentials,
backup и rollback. Дефолт публичной установки остаётся read-only; владелец
своего экземпляра может включить write-профиль явно. Разрешения VK от этого
не расширяются. Отсутствующие user credentials не считаются настроенными.

Для отдельного production OAuth proxy подтверждено автоматическое обновление
действующего ChatGPT grant после естественного истечения access. Auth-код
не менялся: добавлены восемь регрессионных проверок в private инфраструктуре
и [обезличенная инструкция](../oauth-renewal.md).

Тесты core проверяют границы сообществ, обязательные targets для destructive
методов, запрет credential injection, независимые подтверждения и unknown
outcome. Запись и удаления реальных данных при приёмке не выполняются.
Каждый новый upstream метод требует отдельной проверки живых прав.

Локальная проверка: TypeScript build и 55 Node-тестов, включая Python-проверки
операторских helpers; production dependency audit — без известных уязвимостей.
