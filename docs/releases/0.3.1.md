# VK MCP 0.3.1

Добавлен защищённый операторский импорт уже полученного пользовательского ключа:
скрытый ввод, сверка self-ID, семи permission masks, роли администратора каждого
разрешённого сообщества и read-only проверки стены до изменения config.
Ключи и write-профиль сохраняются; пароль VK, токен или redirect URL не попадают
в аргументы команд и отчёт. Сам импортёр не выдаёт доступов и не реализует OAuth.

Исправлено восстановление конфигурации при прерывании Ctrl-C после atomic replace
в операторских helpers. Необрабатываемое завершение процесса/SIGKILL требует
ручного read-back и сверки protected backups; автоматический rollback не обещан
для любого возможного сбоя.

Добавлена [инструкция пользовательского доступа](../user-token.md), проверенная
по текущим официальным документам VK. Создание Web-приложения с базовыми правами
VK ID не открывает остальные API scopes. Для части расширенных доступов VK
требует подтверждения бизнеса и отдельного согласования. Устаревшие способы
получения новых пользовательских ключей не предлагаются.

50 инструментов и 102 действия сохранены. Пользовательский ключ в проверяемом
развёртывании пока не получен; успешные реальные записи и полная статистика
не заявляются. Современный часовой VK token требует отдельного VK refresh flow;
подтверждённый refresh подключения ChatGPT этого не заменяет.

Проверки: TypeScript build и 57 Node-тестов, включая 55 Python cases
операторских helpers; отдельные проверки interruption и current symlink.
